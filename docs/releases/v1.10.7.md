# sgl-node v1.10.7

Text to speech nodes now report a broken speech runtime instead of blaming the input.

Before, any failure while speaking was reported as "this text could not be spoken".
A node whose speech runtime had actually broken (out of memory, a Metal error) kept
being chosen for paid speech requests and failed every one. Now, when speaking fails,
the node re-speaks a short known-good sentence. If that also fails, the node reports a
runtime fault and the Grid stops sending it speech work until it recovers. If the check
passes, the input really was unspeakable and the result is unchanged.

Chat, vision, embeddings and Whisper transcription are unchanged.
