# sgl-node v1.10.2

This release lets a desktop operator pin the exact `llama-server` executable
used to serve a Grid vision model. `sgl start` and `sgl service install` accept
`--llama-server-path` with its SHA-256. The node requires both values, verifies
the canonical executable under an approved install directory, checks its hash
again before launch, and never searches for another engine when a pin is set.

On builds that normally default to in-process inference, a pinned executable
selects the server engine. Explicit `SGL_ENGINE=inprocess` with a server pin is
rejected. A server pin also cannot be applied to embedding or voice workers.
Nodes without these flags retain their existing engine selection.

The Whisper transcription runtime, model, protocol, and price are unchanged.
Vision service setup requires an approved local model, projector, and
`llama-server` build. The node reports the actual server engine in its heartbeat.
