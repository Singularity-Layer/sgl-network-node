# sgl-node v1.12.3

Macs now also stamp each answer with their Secure Enclave key.

On top of the normal signature, every finished answer (and the last piece of a streamed answer) gets a second signature from the key inside the Mac's chip. The Grid checks it and only records the result; nothing is rejected, paid differently or blocked because of it. It adds about 5 milliseconds per answer.

If the chip is slow or fails, the answer is sent exactly as before: each chip signature has a 250 ms limit, and only one runs at a time. Nodes without a Secure Enclave run as before. To turn it off, set `SGL_SE_IDENTITY=0`.
