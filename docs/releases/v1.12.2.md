# sgl-node v1.12.2

Macs now give the node an identity key that lives inside the Mac's Secure Enclave chip.

The key is made inside the chip and cannot be copied off this Mac. The node ties it to its normal identity and reports it to the Grid, which records it. Nothing else changes: no node is blocked, demoted or routed differently, and nodes without a Secure Enclave (Linux, Windows, Intel Macs, virtual machines) run exactly as before.

If anything about the chip key fails or takes longer than 5 seconds, the node simply runs without it. To turn it off, set `SGL_SE_IDENTITY=0`.

This is the first step toward verified Macs. It does not yet prove the software is untouched; that needs Apple's signed device report in a later step.
