# sgl-node v1.12.1

Fixes a sign-in bug that could leave a node unable to serve.

If two logins ran at the same time, the second one replaced the node's key file while the first was still waiting for approval. The first login then registered its own key, so the key on your Mac no longer matched the key the Grid had on file. The Grid rejected everything the node signed and paused it.

Now `sgl login` keeps the key in memory until the Grid has accepted it, saves it only then, checks that the saved key is the registered one, and refuses to start while another login is in progress. If a node is already in this state, log out in the app and connect once. `sgl attest` now says so instead of a bare signature error.
