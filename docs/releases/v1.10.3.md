# sgl-node v1.10.3

This release adds the portable runtime for Singularity xMESH 0.8B, the x402
Multi-Endpoint Selection Head. A node can serve the verified BF16 GGUF through
llama.cpp's native `/v1/systemone` endpoint on Apple silicon, Windows x64,
Linux x64, and Linux ARM64.

xMESH uses a 2,048-token physical batch, one serving slot, an 8 GB nominal
system-memory floor, and CPU execution (`-ngl 0`). GPU offload remains disabled
until accelerator-specific frozen-suite parity passes. The public BF16 artifact
is pinned to 1,571,529,600 bytes and SHA-256
`9f4c08f19c4d203059bc74ed2754e800ec472d7276d8ddb2321480e86d392fff`.

The bundled llama.cpp release advances to `b11719`, the first reviewed build
with the Clef `/v1/systemone` contract. Windows and Linux production
distributions passed the native nine-decision canary with the public model.
Minimal Ubuntu installations receive an actionable `libgomp1` dependency
message if the upstream runtime cannot launch.

System One responses now replace the local GGUF path and caller-supplied model
labels with the authenticated catalog model ID before returning results to the
Grid. Existing chat, vision, embeddings, and Whisper transcription contracts
remain unchanged.
