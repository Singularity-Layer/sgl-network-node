# sgl-node v1.10.4

Singularity xMESH 0.8B now runs on Apple silicon and NVIDIA GPUs.

On the frozen 80-case xMESH suite, llama.cpp `b11719` with full Metal offload
(`-ngl 99`) on an Apple M4 matched the CPU reference on 959 of 960 decisions.
The one difference was a near-tie (50.09% vs 49.91%). Gold accuracy was 854
versus 853, and median latency fell from 4.67 s to 0.82 s per request.

On the same suite, the pinned Vulkan build on an NVIDIA RTX A4000 matched the
CPU reference on all 960 decisions at a 0.31 s median.

xMESH therefore takes full GPU offload on Apple silicon, and on NVIDIA cards
when the node runs the Vulkan llama.cpp build. AMD/Intel Vulkan, CUDA, and
unknown installs stay on the verified CPU path until they pass the same suite. The node chooses this itself; `--gpu-layers` cannot move xMESH off a
verified path. Chat, vision, embeddings, Whisper transcription, and the public
BF16 artifact pin are unchanged.
